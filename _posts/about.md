## Who builds jspassgen?

jspassgen is written by [Sebastien Rousseau](https://sebastienrousseau.com/),
who is on [GitHub](https://github.com/sebastienrousseau) as
sebastienrousseau. The first commit was made in April 2022.

## Project facts

| | |
| :--- | :--- |
| **Package** | [`@sebastienrousseau/jspassgen`](https://www.npmjs.com/package/@sebastienrousseau/jspassgen) on npm |
| **Commands** | `jspassgen` and `password-generator` |
| **Language** | JavaScript, ES modules, with TypeScript declarations |
| **Runtime** | Node.js 22 or newer |
| **Licence** | Apache-2.0 or MIT, at your option |
| **Latest release** | [0.0.20](https://github.com/sebastienrousseau/jspassgen/releases/tag/v0.0.20), 23 October 2026 |
| **Source** | [github.com/sebastienrousseau/jspassgen](https://github.com/sebastienrousseau/jspassgen) |
| **Security policy** | [SECURITY.md](https://github.com/sebastienrousseau/jspassgen/security/policy) |
| **Contact** | hello@jspassgen.com |

## How is it versioned?

jspassgen is pre-1.0 and releases step by 0.0.1 at a time, so any release may
include breaking changes; read the [changelog](/changelog/) before
upgrading.

## How do I get in touch?

- **Bugs and feature requests:** [open an issue](https://github.com/sebastienrousseau/jspassgen/issues).
- **Security problems:** email hello@jspassgen.com, as the
  [security page](/security/) explains. Do not use a public issue.
- **Mistakes on this website:** [open an issue on the site's
  repository](https://github.com/sebastienrousseau/jspassgen.github.io/issues).
- **Anything else:** email hello@jspassgen.com.
