THE PHILOSOPHY

Legacy password generators measure length.
We measure informational entropy.

For three decades, software forced users into artificial composition rules: one uppercase letter, one digit, one symbol. Modern cryptanalysis and GPU clusters crack these predictable patterns in seconds.

jspassgen eliminates superstitious rules in favour of Claude Shannon's information theory, post-quantum KDF primitives (RFC 9106 Argon2id and RFC 5869 HKDF), and client-side memory safety. Every secret is mathematically verified before it touches your clipboard.

01 / QUANTUM HARDENING

Resilient against tomorrow's compute.

Protects credentials against future quantum decryptors and massively parallel ASIC cracking arrays. Under Grover's algorithm, quantum search provides quadratic speedup (O(√N)), meaning 256 bits of symmetric entropy provides 128 bits of post-quantum security. Paired with memory-hard Argon2id (RFC 9106) and HKDF expansion (RFC 5869), brute-force search remains computationally infeasible.

  • Argon2id memory-hardness neutralizes parallel ASIC and quantum oracle evaluations
  • Grover-resistant symmetric bounds (256-bit entropy achieves 128-bit quantum security)
  • Zero-dependency browser-native key derivation via WebCrypto

Frequently Asked Questions

Technical transparency regarding cryptographic primitives, local execution, and verification.

jspassgen is an isolated cryptographic generation tool, not a remote storage vault. Cloud vaults store, synchronize, and auto-fill your credentials across devices, requiring ongoing trust in third-party servers. jspassgen focuses exclusively on generating mathematically uncompromised passwords, Diceware passphrases, and decoy honeywords locally in volatile memory with zero network activity and zero disk persistence.

NIST SP 800-63B (Digital Identity Guidelines) advises minimum length floors of 8 characters (recommending up to 64 or more for automated systems), support for ASCII printable characters, and explicitly rejects superstitious composition mandates (like forcing one symbol or one number) that reduce overall entropy by inducing predictable user habits. jspassgen adheres strictly to these principles by measuring true informational entropy and utilizing hardware-bound CSPRNG.

No. Absolutely nothing leaves your machine. jspassgen executes 100% locally inside your browser using the W3C Web Cryptography API (window.crypto.getRandomValues) or Node.js native crypto module. There are no analytics trackers, no telemetry pings, and no database logs.

Standard random passwords draw uniformly from character alphabets (uppercase, lowercase, numbers, symbols) to maximize entropy density per character. EFF Diceware passphrases draw random words from the curated 7,776-word dictionary compiled by the Electronic Frontier Foundation. A 5-word Diceware passphrase provides approximately 65 bits of entropy and is exceptionally easy for humans to type and remember, while remaining immune to brute-force dictionary attacks.

Invented by cryptographic researchers Ari Juels and Ronald L. Rivest (ACM CCS 2013), the Honeywords defense stores k - 1 decoy passwords alongside the genuine password in a hashed credential store. To an external attacker who dumps the database and cracks the hashes, all k passwords appear equally valid. When the attacker attempts to authenticate with any decoy password, a canary trap immediately alerts security operations and freezes the compromised account before the attacker can test the real password.

Naive password meters simply count length or reward predictable patterns like adding an exclamation mark at the end. Claude Shannon's information entropy formula H(X) = -∑ p(x) log₂(p(x)) measures the exact uncertainty and unpredictability of the symbol probability distribution. This reveals whether a password has true cryptographic variance or repetitive bias.
