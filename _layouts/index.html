What it does

Passwords from a cryptographic random source, with the maths shown

Each card opens its section on the features page.

Eight password types

Random strings, Base64, EFF word passphrases, Diceware, pronounceable syllables, custom character sets and honeyword decoy sets.

Compare the types

Cryptographic random source

Characters and words are drawn with Node.js crypto, and rejection sampling keeps every character of the set equally likely.

How randomness is drawn

An entropy estimate

Every result comes with its entropy in bits, worked out from the size of the character set or word list and the length.

How it is calculated

Presets and bulk output

Six presets cover common cases in one flag, and -n prints many passwords at once as text, JSON, CSV or YAML.

See the presets

Honeywords

A set of look-alike passwords with one real one among them. Stored as decoys, they help a server notice a stolen password database.

How honeyword sets work

A dependency-free core

The generators live in a core package with no dependencies, which takes its random source as a parameter so the same code runs in Node.js and the browser.

Install

From the terminal or from your code

Run it with npx, install the command globally, or import it as an ES module. jspassgen needs Node.js 22 or newer.

  • npx @sebastienrousseau/jspassgen -p quick
  • npm install @sebastienrousseau/jspassgen
Read the getting started guide
Security

A generator, not a vault

jspassgen creates passwords. It does not store, hash, sync or send them anywhere.

Store what it generates in a password manager, and hash passwords on the server with a key-derivation function such as Argon2id, scrypt or bcrypt. The security page says what jspassgen does and does not protect against.
